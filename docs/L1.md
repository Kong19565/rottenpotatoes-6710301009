## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | starter ที่รวม library สำหรับทดสอบไว้ชุดเดียว (JUnit, AssertJ, Mockito, Spring Test ฯลฯ) ใส่ dependency ตัวเดียวแล้วได้ครบ และ Spring Boot กำหนดรุ่นให้เข้ากันเอง |
| junit-jupiter | framework สำหรับเขียนและรัน test (`@Test`) ใน JUnit 6 ประกอบด้วย api สำหรับเขียน test, engine ที่รัน test และ params สำหรับ test แบบใส่หลายค่า |
| assertj-core | library สำหรับเขียน assertion แบบอ่านเป็นประโยค เช่น `assertThat(FizzBuzz.of(3)).isEqualTo("Fizz")` และให้ข้อความ error ที่ชัด (expected ... but was ...) |
| mockito-core | สร้าง test double (mock/stub) แทน object จริง เพื่อทดสอบ class หนึ่งโดยไม่ต้องพึ่ง database หรือ service ภายนอก (จะใช้ในสัปดาห์ที่ 9) |
| spring-test | เครื่องมือทดสอบของ Spring Framework เช่น โหลด Spring context ใน test และทดสอบ controller ด้วย MockMvc (ใช้กับ slice test ในสัปดาห์ที่ 6–7) |
| hamcrest | library สำหรับเขียน matcher ใน assertion อีกแบบหนึ่ง (`assertThat(x, is(3))`) เป็นทางเลือกของ AssertJ |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้

   red bar พิสูจน์ว่า test ตรวจผลจริงและจับความผิดได้ ตอน stub คืน `""` test ล้มทั้ง 4 ข้อด้วยข้อความ `expected "Fizz" but was ""` ถ้าเห็นแค่ green เราจะไม่รู้ว่า test ผ่านเพราะโค้ดถูก หรือเพราะ test ไม่ได้ตรวจอะไรเลย นอกจากนี้ red แบบแรกที่ compile ไม่ผ่านกับ red จริงที่ test ล้มเป็นคนละอย่างกัน red ที่นับคือแบบหลัง
